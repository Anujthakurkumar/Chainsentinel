Place your MaxMind GeoLite2 files here:
  GeoLite2-City.mmdb
  GeoLite2-ASN.mmdb

These are NOT included in this repo/zip — MaxMind's license prohibits
redistributing the raw database files.

Free signup (2 minutes): https://www.maxmind.com/en/geolite2/signup
Under "Manage License Keys", generate a key, then download both files above
and drop them directly in this folder.

If this folder is empty, the pipeline still runs fully offline — it
automatically falls back to a deterministic synthetic GeoIP mapping and
prints "synthetic fallback" so you always know which mode it's using.
